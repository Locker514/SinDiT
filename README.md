# SinDiT
Official implementation of SinDiT for low-sample industrial surface defect augmentation

This repository is associated with the manuscript:

> Latent single-image diffusion augmentation for low-sample industrial surface defect detection

The source code and reproduction materials for SinDiT are currently being prepared and will be released in this repository after publication of the paper.

At present, this repository does not contain the implementation, datasets, pretrained weights, or experimental results.

## Status

Code release: planned after publication.

## Citation

If you use this repository or the associated method, please cite the paper after its publication.
